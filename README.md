# Seonsoo Kim's website

Published at https://seonsoo-p1.github.io/SeonsooKim.github.io/ through GitHub Pages
from the root of the `master` branch. The design is based on
[Jon Barron's academic website template](https://jonbarron.info/).

## Visit counter

The homepage footer uses a dedicated [Flag Counter](https://info.flagcounter.com/Ax3O)
created for this website on September 8, 2026. Its public counter ID is `Ax3O` on
`s01.flagcounter.com`. If you copy this website, generate your own counter at
https://flagcounter.com/; reusing this ID would mix your traffic into this site's counts.

- The widget shows estimated visits by country; clicking it opens totals and history.
- By default, Flag Counter counts the same IP once per 24 hours. Reloading the page
  adds pageviews in the dashboard but does not add another visit within that period.
  Pageviews are deliberately hidden in the footer.
- This is not a count of distinct people. Shared IPs can group people together;
  changing IPs and bots can add visits, and blocked images can miss visits.
- Counts start with this installation. Previous Who's Among Us statistics are not
  imported because that widget used a shared counter. Verification visits may be included.
- Image counts may lag the dashboard by about five minutes. The image loads with
  the page rather than waiting for the reader to scroll to the footer.
- To exclude your own browser, click **Ignore this browser** at the bottom of the
  [statistics page](https://info.flagcounter.com/Ax3O). Local previews also count
  unless that browser is excluded or the counter image request is blocked.
- No email address or paid account was used. Management-only settings and private
  statistics are unavailable for this counter. The free service can delete counters
  after 30 days without a new visitor; it is not a permanent analytics archive.

See the provider's [counting FAQ](https://flagcounter.com/faq.html) and
[privacy policy](https://flagcounter.com/privacy.html). The embedded image uses no
cookies; the provider uses a temporary IP-derived hash for repeat-visit filtering.
